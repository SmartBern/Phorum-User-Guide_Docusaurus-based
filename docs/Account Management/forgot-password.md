# Forgot Password

This page enables unauthenticated users to change their password. 

For now, the primary way to recover and set a new password is to remember the security answer to the security question selected during registration.

- Click on **Forgot Password** at the bottom of the login page.

    ![Forgot Password Page Link](/img/screenshots/forgot_password_page_link.png)

- This will open up the following page:

    ![Find Account Page](/img/screenshots/find_account_page.png)

- Enter your username and click **Find Account** to fetch your account.

    ![Username in Forgot Password Page](/img/screenshots/username_forgot_password_page.png)

- This opens up the following page:

    ![Forgot Password Page](/img/screenshots/reset_password_page.png)

- Enter your security answer.

- Create a new password.

- Retype your new password.

- Click the **Reset Password** button to reset your password.

- You can then proceed to log in with your username and new password.
