# Managing Your Profile

Your profile page can be accessed through clicking on the **Profile** button in the desktop navbar or the **Profile** link in the mobile navigation menu.

![Profile button in desktop navbar](/img/screenshots/profile_button.png)

![Profile link in mobile nav menu](/img/screenshots/profile_button_mobile.png)

Clicking the profile button or the profile link opens up the page as follows:

![Profile Page](/img/screenshots/profile_page.png)

Your profile page contains the following:

- Username.

- A profile picture (if uploaded) with Change Image and Delete Image buttons or the first initial of your username displayed boldly.

- Date of account creation.

- Last online activity.

- A **Change Password** button.

    ![Change Password Page](/img/screenshots/change_password_page.png)

- A **Post** tab showing all the posts you have created under different sections.

- A **Liked Posts** tab showing all the posts you have liked under different sections.
