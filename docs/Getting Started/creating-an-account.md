# Creating an Account

Creating an account on Phorum is straightforward.

1. From the homepage, click **Register**.

    ![Phorum registration page link](/img/screenshots/register_on_phorum.png)

    This will take you to the account creation page.

    ![Phorum registration form](/img/screenshots/register_form.png)

2. Enter a username.

3. Enter a password.

4. Select a security question.

5. Enter an answer to the security question.

6. Click the **Register** button to save your details and create a new account.
