# Welcome to Phorum

Phorum is a discussion platform/forum where users can
create posts, participate in discussions, and
interact with other users.

This guide explains how to use Phorum's features
and manage your account.

## Who is this guide for?

This guide is intended for users who want to
learn how to navigate and use Phorum.

## What you will learn

- How to access the application
- How to create and manage posts
- How to interact with other users
- How to manage your profile
