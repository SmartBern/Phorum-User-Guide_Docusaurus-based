# Commenting on a Post

- Select the post you want to comment on from any of the sections.

- Click on the post's title, *Read more*, or comments to navigate to the post page.

- From the post page, you will see the comment box directly under the post.

    ![Comment box under the post](/img/screenshots/comment_box.png)

- To add a new comment, you need to enter a minimum of 15 characters into the box before the **Add Comment** button can be activated.

    ![New comment on post](/img/screenshots/new_comment.png)

- After the **Add Comment** button is clicked, the new comment appears below the comment box.

    ![New comment added](/img/screenshots/new_comment_added.png)

- The comments count for the post increments on all pages.
