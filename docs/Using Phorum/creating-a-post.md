# Creating a Post

- An authenticated user can create a new post by clicking on the **Create Post** button on the homepage.

    ![Create post button](/img/screenshots/create_post_button.png)

- This button leads to a form for creating a new post.

    ![Create post form](/img/screenshots/create_post_form.png)

- Enter the title for your post.

- Enter the post text.

- Select an appropriate section for your post.

- Upload and add an image to your post (optional).

- Click the **Create Post** button to submit and create your new post.

- The new post will appear on the homepage, above existing posts.
