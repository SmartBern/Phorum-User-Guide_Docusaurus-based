# Deleting a Comment

This follows quite a similar step to editing a comment, with only the end result being different.

- An authenticated user can delete a self-made comment only on the **post page**.

- To delete a comment, click on the three dots at the topmost right corner of the comment.

    ![Edit and delete comment icon](/img/screenshots/edit_comment_dots.png)

- Clicking these dots reveal the **Delete Comment** option.

    ![Delete comment option](/img/screenshots/edit_comment_option.png)

- Clicking the **Delete Comment** option bring up the following modal:

    ![Delete comment option](/img/screenshots/delete_comment_modal.png)

- Clicking **Yes** deletes the comment from the post page and decrements the comments counts for that post on all pages.

- Clicking **No** cancels the comment delete action and you will remain on the post page.
