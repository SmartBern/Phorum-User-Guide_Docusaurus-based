# Deleting a Post

This follows quite a similar step to editing a post, with only the end result being different.

- An authenticated user can delete a self-made post only on the **post page**.

- To delete a post, click on the three dots at the topmost right corner of the post.

    ![Edit and delete post icon](/img/screenshots/edit_post_icon.png)

- Clicking these dots reveal the **Delete Post** option.

    ![Delete post option](/img/screenshots/edit_post_option.png)

- Clicking the **Delete Post** option bring up the following modal:

    ![Delete post option](/img/screenshots/delete_modal.png)

- Clicking **Yes** deletes the post from both the post page and the homepage. You will be redirected to the homepage after this action is completed.

- Clicking **No** cancels the delete action and you will remain on the post page.
