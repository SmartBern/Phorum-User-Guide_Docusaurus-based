# Editing a Comment

- To edit a comment, click on the three dots at the topmost right corner of the comment.

    ![Edit and delete comment icon](/img/screenshots/edit_comment_dots.png)

- Clicking these dots reveal the **Edit Comment** option.

    ![Edit comment option](/img/screenshots/edit_comment_option.png)

- Clicking the **Edit Comment** option reveals a modal, where the comment can be edited.

    ![Editing a comment](/img/screenshots/editing_comment.png)

- Change or modify the comment body

- Click the **Save** button to save the changes made to the comment. These changes appear immediately on the comment.

    ![Edited comment](/img/screenshots/edited_comment.png)
