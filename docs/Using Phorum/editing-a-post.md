# Editing a Post

- An authenticated user can edit a self-made post only on the **post page**.

- To edit a post, click on the three dots at the topmost right corner of the post.

    ![Edit and delete post icon](/img/screenshots/edit_post_icon.png)

- Clicking these dots reveal the **Edit Post** option.

    ![Edit post option](/img/screenshots/edit_post_option.png)

- Clicking the **Edit Post** option reveals a modal, where all the necessary changes can be made.

    ![Edit post modal](/img/screenshots/edit_post_modal.png)

- Change or modify the title.

- Change or modify the post text.

- Upload or add a new image to the post.

- Click the **Save** button to save the changes made to the post. These changes appear immediately on the post in both the homepage and the post page.
