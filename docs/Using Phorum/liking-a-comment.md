# Liking a Comment

Every comment under a post's page carries a like (thumbs up) button.

- Liking a comment turns the thumbs up button to red and increment the likes count on the comment.

    ![Liked comments](/img/screenshots/liked_comment.png)

- Every liked comments under different posts retains the red thumbs up.

- Unliking a comment returns the thumbs up button to gray and decrement the likes count on the comment.

    ![Unliked comments](/img/screenshots/unliked_comment.png)
