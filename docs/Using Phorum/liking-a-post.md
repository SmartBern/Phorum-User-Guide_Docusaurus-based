# Liking a Post

- An authenticated user can like a self-made post or other users' post either on the homepage or on the post page.

- Liking a post increments the likes count on the post and unliking the post decrements the likes count on that post.

- Liked posts on the homepage (under any section) and post page permanently have red thumbs-up.
