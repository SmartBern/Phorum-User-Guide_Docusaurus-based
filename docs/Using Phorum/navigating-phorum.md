# Navigating Phorum

The phorum homepage is accessible to both guests and authenticated users. However, there is a distinction in what both categories of users can do on the homepage.

- A guest can only view the topics and navigate the different sections on the homepage

- An authenticated user can view the topics and navigate the different sections on the homepage, and use every other features of the platform.
