# Replying to a Comment

An authenticated user can reply to any comment under any post.

- Select the comment you want to reply to.

    ![Reply to comment](/img/screenshots/comment_under_post.png)

- Click the **Reply** button to add your reply.

- This opens up the reply box where you can type your reply to the comment.

    ![Comment reply box](/img/screenshots/comment_reply_box.png)

    ![Typed reply](/img/screenshots/new_reply.png)

- Click on the **Reply** button below the reply box to add your reply to the comment.

    ![New reply added](/img/screenshots/new_reply_added.png)
